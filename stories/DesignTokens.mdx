# Design Tokens

Every Estiva component references these tokens, never raw hex. Each swatch
reads a live CSS variable, so it shows the theme selected in the **Theme**
toolbar: `light` and `dark` are Peek's values, `ship` is Ship's. The names are
the ones you use in code: a colour token `bg-surface` is the Tailwind class
`bg-bg-surface`; a type token `body-2` is `text-body-2`.

> Source of truth: `tailwind-preset.js` (the names, plus the type / radius /
> shadow scales) and `tokens.css` (the values, one block per theme).
> `npm test` checks that every theme defines every name, and no other.

## Typography

Font family is **Geist**. The ramp pairs headings, body, and component-specific
sizes. Component tokens (`btn-*`, `input-*`, `chip`) are deliberately explicit —
in shared components prefer arbitrary values (`text-[12px] leading-[12px]`),
because tailwind-merge silently drops a custom size class that is followed by a
`text-{colour}` class.
