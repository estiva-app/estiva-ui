# Design Tokens

The vocabulary every Estiva surface is written in — never raw hex. Every
swatch reads its live CSS variable, so the **Theme** toolbar switches this
whole page between the package's themes.

The name is the class: colour token `surface` in the Background row is
`bg-bg-surface`, text colour `secondary` is `text-text-secondary`, type
token `body-2` is `text-body-2`. The names live in `tailwind-preset.js`,
the values in `tokens.css` (one block per theme), and `npm test` proves
every theme defines every name — and no other.
