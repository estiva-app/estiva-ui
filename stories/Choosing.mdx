# Choosing a component

Find what you need; take the row. When nothing fits, build it in your app —
and if what you built knows nothing about your product's objects, propose
it for the package. A component that nearly fits is **forked, not fought**:
fork freely, owe nothing back, mention it on the package's ticket.

## An action

| You need | Reach for |
|---|---|
| A labeled action — a verb, clicked once | **Button** — `primary` at most once per surface |
| An icon-only action | **IconButton** — it requires an `aria-label` |
| An action in a popover list | **MenuItem**, inside a **Menu** |
| A destructive action | **Button** `destructive`, guarded by a **ConfirmDialog** |

## A choice

| You need | Reach for | Not |
|---|---|---|
| One value for a form field | **Select** | a Menu — Select's trigger shows the value |
| Several values, typed then removable | **ChipInput** | checkboxes in a Menu |
| Yes or no | **Checkbox** | a toggle we don't have |
| Yes or no, with words beside it that toggle it too | **Checkbox** `label` | words written beside it by hand — they name nothing and toggle nothing |
| Switching between views of one thing | **Tabs** | a row of Buttons |
| View options behind a `…` | **Menu**, `selected` on the current row | Select |
| Rows of checkboxes that stay open | **Checkbox** `row`, in a list in a **DialogShell** | a Menu — a Checkbox inside a `menuitem` is invalid HTML; a row with `role="option"` drawn by hand |

## Typing

| You need | Reach for |
|---|---|
| One line | **TextInput** |
| One line in a dense row, beside small selects | **TextInput** `size="small"` — 24px, the small Select's height |
| Several lines | **Textarea** |
| Typing that filters a list | **SearchInput** |
| A title edited in place | **EditableText** |
| Label and required-mark around any control | **Field** |
| The fields and the button that sends them | **Form** — Enter sends; `busy` switches everything inside off while it waits |
| A button that opens the file picker | **FilePicker**, opened by your own **Button** or **IconButton** |
| A hint or a failure under **one** control | **Field**'s `helper` / `error` — wired to it, and announced |
| A hint or an outcome under a **group** of controls | **FieldLine** — the same line on its own, with a `warning` tone Field has not got |

## People

| You need | Reach for |
|---|---|
| One face | **Avatar** |
| Several faces, overlapping | **AvatarGroup** |
| Face and name in a row | **Person** |
| The face that opens a menu | **PersonTrigger** |
| Who you are, where you are, sign out | **IdentityMenu** — the account menu, ready-made |

## Floating surfaces

| You need | Reach for |
|---|---|
| A list of verbs from a trigger | **Menu** — Escape, outside-click and the arrow keys come with it |
| A panel of *content* from a trigger — a field, a toolbar, a small form | **Popover** — the menu's surface without a menu's keyboard |
| More of a thing on hover | **PreviewCard** — unlike a tooltip, you can point at it |
| A hint on hover or on keyboard focus | **Tooltip** / **WithTooltip** — one `TooltipProvider` at the app root shares the delay |
| A strip of controls that act on one thing | **Toolbar** — one Tab stop for the row, arrow keys along it |
| Reactions to choose from | **ReactionPicker** — the row; **Reaction** is the pill it produces |
| One window to find something and act on it, opened by a shortcut | **CommandPalette** — rows, forms and written answers, one level at a time |
| Anything with a title, body and footer | **DialogShell** |
| "Are you sure?" | **ConfirmDialog** |
| A picture full screen, from a thumbnail | **Lightbox** — an **AttachmentCard** opens one by itself |

## Structure and wayfinding

| You need | Reach for |
|---|---|
| Label–value rows (a details rail) | **Property** — `row` and `stacked` |
| The bar across the top of a column: its title, and the buttons that act on the whole column | **ContainerHeader** — one per column; the actions as IconButtons in `actions` |
| A box that can hold more than fits — a list that grows with its data counts, even when today's data fits | **ScrollArea** — its bar is drawn over the content and takes no width |
| A status, a count or a category, in a small pill | **Chip** — six colour types; the colour is the message, the label makes it legible |
| One thing — a conversation, a project, an object — as a box you can pick | **Card** — the fill by what it sits on; `href` for a link, `hover="fill"` in a feed |
| A section heading, chevron, hover actions | **SectionHeader** |
| A group of rows that opens and closes, and stays how you left it | **CollapsibleSection** — `storageKey` remembers |
| The uppercase micro-label | **SectionLabel** |
| A hairline | **Divider** |
| Where am I, and the way back up | **Breadcrumb** |
| A link — in text, on a title, beside a note, or a whole box | **Link** — `text`, `quiet`, `underlined`, `plain`; `external` for a new tab |
| A document or an image attached to something, posted or waiting to be sent | **AttachmentCard** — the file decides the shape; `pending` in a composer |
| A person or a thing named inside a sentence | **InlineChip** — one line high, level with the words; `href` makes it a link |
| The key that does this too | **Kbd** — or the `shortcut` prop on **MenuItem**, **Tooltip** and **SearchInput** |

## Feedback

| You need | Reach for |
|---|---|
| Data is on its way | **Skeleton** — shaped like what will arrive |
| How much of something is done | **ProgressBar** — `default` to be read, with the words beside it; `quiet` for a glance beside a count |
| Nothing to show | **EmptyState** — says what would fill it; `page` when the whole page is empty (icon, centred), `section` when one part of it is (the line alone, left) |
| It happened, briefly | **Toast**, via `useToast` inside a `ToastProvider` |
| It happened, and must not be missed | **Toast** with `durationMs: 0` and an action — it floats and stays until dismissed (D21) |
| The whole surface has something to say | **Banner** — the strip under the top bar, full width; `onDismiss` if the reader closes it rather than the app |
| A part that breaks without taking the page with it | **ErrorBoundary** — around each column, panel or conversation, and once around the app; `label` says what it holds |

## The frame

Two frames, two pairs: the **solid** TopBar goes with the **Sidebar**;
the **floating** TopBar goes with the **Rail** and the content card.

| You need | Reach for |
|---|---|
| The structured frame: solid bar, sidebar, content | **AppShell** `solid` |
| The floating frame: bar over the content, rail, rounded card | **AppShell** `floating` |
| The 52px bar alone | **TopBar** — `solid` in flow, or `floating` over the content |
| A 240px navigation column | **Sidebar**, filled with **NavItem** rows |
| A 64px icon strip | **Rail**, filled with **RailItem** tiles |
| The menu button and the logo | the TopBar's `menu` and `logo` slots — collapsing stays yours |
| The list beside the thing that is open | **ListColumn** — 290px, its name in a **ContainerHeader**, the list under it scrolling |

## Deliberately not in the package

- Anything that knows your **product's objects** — its documents, threads,
  files, tickets. Build it in your app, out of these parts, and keep its
  stories in your app's own Storybook.
- Page layouts beyond the list column (**ListColumn**) and a column's bar
  (**ContainerHeader**) — split views, side rails — not here yet.
