# ConversationMenu

The ⋯ menu of a comment or a reply: Resolve or Reopen and the app's own rows; then Edit on your own; then Delete on your own, apart.

<Canvas of={Stories.Yours} />

## When

- Inside **ConversationCard** and **ReplyCard**, which draw it for you.
- Its `children` are the app's own rows, after Resolve; `after`, its rows after Edit.
- In the app's own words: `label` heads the first rows, `resolveHint` stands beside Resolve, `editLabel` is Edit's word. Peek's menu reads as it did with them (Katerina, 1 November).
- `deleteLabel` is Delete's words ("Delete message"), and `moreLabel` names its own ⋯ button, its tooltip too, when no `trigger` is given ("More actions" by default; "Message actions"). Ship's menu reads as it did with them (2 November).

## When not

- Any other menu → **Menu**.

## How

```tsx
import { ConversationMenu, MenuItem } from '@estiva-app/ui'

<ConversationMenu onResolve={resolve} onEdit={edit} onDelete={askToDelete}>
  <MenuItem label="Item one" onClick={doSomething} />
</ConversationMenu>
```

- Edit and Delete are offered on your own only: pass them only there.

## What it owns

| It does | So you never write | Refused when written by hand |
|---|---|---|
| Offers Reopen in place of Resolve once resolved | the swap |  |
| Draws Edit and Delete only when handed them | a check for whose it is |  |
| Puts the app's own rows between Resolve and Edit, with the lines between groups | separators |  |
