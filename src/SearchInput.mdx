# SearchInput

An inset field with a hairline border that strengthens on hover and on
focus, and an optional keyboard hint at the right edge.

<Canvas of={SearchInputStories.WithShortcut} />

## When

- Filtering a list, live, above the list it filters.
- As a **launcher affordance**: keep the input `pointer-events-none` and
  open your command surface from a click on the surround — the component
  is the same either way, and `shortcut` shows the way in ("Ctrl+K").

## When not

- General text entry → **TextInput**.
- Picking entries from a directory → **ChipInput** or **Select**.

## How

```tsx
import { SearchInput } from '@estiva-app/ui'

<SearchInput value={query} onChange={(e) => setQuery(e.target.value)} shortcut="Ctrl+K" />
```

- The default placeholder is "Search…" — override it with your own.
- Every native input prop passes through. The field inside is Base UI's
  `Input` since stage 3; the border, the focus-within rule and the `Kbd`
  hint are this component's.
- **Give it an `aria-label` ("Search")** — the placeholder is not a name,
  and this usually stands alone in a top bar rather than in a `Field`.
  Inside one, the label names it and you add nothing.
