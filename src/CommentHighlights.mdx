# CommentHighlights

Comments drawn on the words they are about, in an editor of a block document: every commented run in a light fill, the open one underlined.

*Prototype (Leaf, 9 October), not reviewed.*

<Canvas of={CommentHighlightsStories.Default} />

## When

- **Comments on a few words of a block document.** SPEC §13.6 anchors a comment to one block; the words travel with it as a quote and are found again inside that block when the document is drawn.
- `setCommentAnchors(editor, anchors, active)` draws them; `active` is the one being read.
- The editor's `commentSelect` event says which highlight was clicked.
- `commentRange` returning `null` is §13.6's **detached**: the words were changed or deleted. Say so; never show it as a comment on the whole document.
- `quoteOfSelection` is what a comment on the selection carries: its block and its words.

<Canvas of={CommentHighlightsStories.NoneOpen} />

## When not

- Showing a selection while a field has the focus → **SelectionToolbar**'s kept selection.

No alternative: a comment on the whole document has no words to draw. Say where it belongs in words.

## How

```tsx
import { useEffect } from 'react'
import { useEditor } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'
import { BlockId, CommentHighlights, setCommentAnchors } from '@estiva-app/ui/editor'

const editor = useEditor({ extensions: [StarterKit, BlockId, CommentHighlights] })

useEffect(() => {
  if (!editor) return
  setCommentAnchors(editor, threads, openId)
  const select = ({ id }: { id: string }) => open(id)
  editor.on('commentSelect', select)
  return () => { editor.off('commentSelect', select) }
}, [editor, threads, openId])
```

- **Nothing is written into the document.** The highlight is a decoration: a save never carries it.
- `BlockId` must be in the editor: the anchors find their block by its id.
- The quote is matched exactly, within its block. Two equal runs in one block: the first is drawn.

## What it owns

| It does | So you never write |
|---|---|
| Finds the words again in their block, after every edit | position arithmetic |
| Draws them, and the open one underlined | a mark in the document |
| Says which highlight was clicked | a click handler on the text |
