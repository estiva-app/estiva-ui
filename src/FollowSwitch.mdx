# FollowSwitch

How you follow a place, in one button before its title: Not following,
Important or All, and back to a group's default when you chose against it.

<Canvas of={FollowSwitchStories.Live} />

## When

- Before a place's title, where the viewer changes how it lights for them.
- **LevelIcon** alone, in a list of places, where each row shows the level but
  is not the place to change it.

## When not

- Who else follows it, and adding someone → **WhoFollowsDialog**.
- Being in a thing or not, with no levels → **MembersDialog**'s Join and Leave.

## How

```tsx
import { FollowSwitch, LevelIcon, type FollowChoice } from '@estiva-app/ui'

const level: 'all' | 'important' | undefined = 'important'

<FollowSwitch
  level={level}
  label="Item one"
  onChoose={async (choice: FollowChoice) => {}}
  backTo={undefined}
/>

<LevelIcon level={level} />
```

- `level` is what lights for the viewer now; `undefined` is Not following.
  The switch is controlled: it draws the `level` it is given, so pass the new
  one once the change is saved.
- `onChoose` gets `'off'`, `'important'`, `'all'`, or `'default'` from "Back to
  Group one’s default". The button waits while its promise runs. Leave it out where
  the level cannot change: the button then shows it and is disabled.
- `backTo` is the name of the group whose default the viewer chose against.
  Leave it out when no default reaches them or they did not choose against it.
- `people` draws people instead of circles, for a place that is a group's own.
- `files` says whether the place lists files (a topic, a space; the default).
  Each level's line then says what of them the place shows and what lights:
  "Shows its own conversation. Lights for new conversations, replies in yours,
  and what names you on its files." Pass `false` for a place with none (a
  team's chat): the lines say only what lights, "Lights for every message".
- `label` is the place's name. The button's accessible name says the level and
  what pressing it does: "You follow it at Important: change how you follow
  Item one".

## What it owns

| It does | So you never write | Refused when written by hand |
|---|---|---|
| Marks the level in force with a check, and Not following when there is none | a selected state per row |  |
| Waits while `onChoose` runs, so one pick is one change | a busy flag around it |  |
| Offers "Back to `backTo`’s default" only when `backTo` is given | a second menu section |  |
