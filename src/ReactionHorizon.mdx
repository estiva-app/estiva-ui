# ReactionHorizon

The line that says reactions are read only so far back, and how many older comments were not checked.

<Canvas of={Stories.Older} />

## When

- Under a long conversation, when the app stopped reading reactions before the oldest comment.
- `keepRoom`, while only the newest comments are read and the whole read will need the line: its room is kept, unseen, so the comments do not move up when the rest lands.

## When not

No alternative: when every reaction was read, it draws nothing, so it can always be placed.

## How

```tsx
import { ReactionHorizon } from '@estiva-app/ui'

<ReactionHorizon limit={200} omitted={14} cut={false} />
```

- `limit`, `omitted` and `cut` are the app's to count.
- `noun` is what the app calls what is said, in the plural: "messages" in Peek. "comments" by default.
- `keepRoom` is the app's to know: more is coming and it will be past `limit`. Nothing to draw a second, invisible line for.

## What it owns

Nothing. It only draws. Clicks and keys are yours.
