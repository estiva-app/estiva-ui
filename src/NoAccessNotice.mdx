# NoAccessNotice

Where a link to a file you can't read opens: "You can't open this …", and no title.

<Canvas of={Stories.Page} />

## When

- The page a link opens, when the file is not yours to read. The page holds the line alone.

## When not

- Under a message → **LinkRow** or **LinkCard** with the link unavailable: the same words, on the link's own card.
- A file that was deleted → **DeletedNotice**, which says who deleted it.
- A page with nothing in it yet → **EmptyState**.

## How

```tsx
import { NoAccessNotice } from '@estiva-app/ui'

<NoAccessNotice what="page" />
```

- `what` is the kind of file, in the app's words. Never pass its title: the line exists so a link tells someone who can't read the file nothing about it.
